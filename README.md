# albahaclub-board
Al Baha Literary Club Board Managwment Platform
## Project Overview

A private management system developed for an organization to help manage and organize internal council operations in a simple, efficient, and professional way.

The system provides a centralized platform for managing meetings, minutes, tasks, decisions, voting, documents, and reports with user authentication and role-based access control.

---

## Features

###  Dashboard
- Overview of the organization's activities.
- Clean and user-friendly interface.
- Arabic RTL supported design.

###  Meetings Management
- Create new meetings.
- Edit and delete meetings.
- Track meeting status and details.

###  Minutes Management
- Create and manage meeting minutes.
- Link minutes with meetings.
- Update and store meeting details.

###  Tasks Management
- Create and assign tasks.
- Set deadlines and responsibilities.
- Track task status.

###  Decisions Management
- Add organizational decisions.
- Update decision details.
- Track decision status.

###  Voting System
- Create internal polls and voting sessions.
- Allow users to participate and view results.

###  Files & Documents
- Upload and manage documents.
- Store important files securely.
- Download available documents.

### Reports Management
- Add and manage reports.
- Upload report attachments.
- Edit report information.

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6 Modules)
- Firebase Authentication
- Firebase Firestore
- Firebase Hosting

---

## Database

Firebase Firestore is used to manage and store:

- Users and permissions
- Meetings
- Minutes
- Tasks
- Decisions
- Voting records
- Files
- Reports

---

## User Roles

The system supports role-based access:

### Admin
- Add, edit, and delete system content.
- Manage organizational records.

### Members
- View available information and participate in allowed activities.

---

## Purpose

The goal of this project is to provide a digital platform that improves internal organization, simplifies information management, and enhances workflow efficiency.
